# alwaleed-finance
أريد استخدام Render لنشر المنصة. أرشدني خطوة بخطوة من البداية، وساعدني في رفع ملف المشروع alwaleed-finance-platform.tar.gz وإعداد قاعدة البيانات الدائمة ونشر الموقع.  أريد أن تنفذ معي جميع خطوات النشر حتى أحصل على رابط HTTPS دائم يعمل من الهاتف والكمبيوتر، مع التأكد من عمل تسجيل الدخول وإضافة وتعديل وحذف البيانات وحفظها بعد تحديث الصفحة.
